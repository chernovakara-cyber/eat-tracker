# Мой БЖУ дневник

Готовый статический сайт для GitHub Pages.

## Что умеет
- отдельные цели по белкам, жирам и углеводам на каждый день;
- дневник еды по датам;
- возможность открыть вчерашний или любой другой день и дописать записи;
- подсчёт БЖУ и калорий;
- редактируемая база продуктов;
- голосовой ввод через Web Speech API, если браузер его поддерживает;
- хранение данных в localStorage браузера.

## Как опубликовать через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `app.js`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`.
6. Сохрани настройки.

## Важно
Данные сохраняются только в браузере и на конкретном устройстве. Если очистить данные сайта или открыть сайт на другом устройстве, записи не появятся автоматически.
