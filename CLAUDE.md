# Дневник питания — памятка для Claude

Сайт: https://chernovakara-cyber.github.io/eat-tracker/

Всё приложение — один файл `index.html` (HTML + CSS + JS, без сборки). `old.html` — самая первая версия, не трогать.
Картинки в корне: `chicken.png` / `chicken-sad.png` (белки), `avocado*.png` (жиры), `pasta*.png` (углеводы). `salad.png` и `white-heart.png` (мишка) сейчас не используются, салат, возможно, вернём.

## Данные
- Только localStorage браузера: `eatTrackerDays_v6` (дни: `targets {protein, fat, carbs}`, `entries`) и `eatTrackerProducts_v6` (мои продукты: БЖУ на 100 г, `piece` — вес 1 шт, `countProtein`).
- Ключи не менять — иначе пропадут записи. Синхронизации между устройствами нет, у каждого человека свои данные.
- Новый день берёт норму из последнего заполненного дня.

## Правила нормы
- Белки: в норме, только если съедено не меньше нормы (перебор белка — хорошо).
- Жиры: норма ±5 г. Углеводы: норма ±10 г. Меньше — «не добраны», больше — «Перебор …» и красная карточка.
- В норме: еда улыбается, галочка на иконке, подпись «Белок добран / Жиры в норме / Углеводы в норме». Иначе еда плачет.
- Календарь: сердечко — все три в норме; крестик — прошедший день с записями вне нормы; сегодня крестик не ставится.

## Разбор фраз (голос и текст)
- Голос — Web Speech API браузера (ru-RU), без Claude и без сервера.
- Порядок слов любой; «белки 13» и «13 белков»; числа словами (в том числе «двух», «трёх»).
- «На 100 г» → БЖУ пересчитывается на названные граммы. Без «на 100 г» цифры — это то, что съедено.
- Продукты из «Моих продуктов» узнаются по основе слова («гречки», «куриной грудки») — достаточно назвать граммы.
- Вес 1 шт только у яиц (60 г), яичного белка (40 г) и желтка (20 г). Остальные продукты — только граммы.
- Новый продукт с названным БЖУ → кнопка «Сохранить в мои продукты».

## Дизайн
- Розовый «девчачий» стиль: матовое стекло на пудрово-розовом фоне, одно мягкое размытое сердце справа вверху, тонкий шрифт Raleway, ягодный акцент #b8436c.
- Порядок блоков: дата → полоска дней недели (полный календарь открывается кнопкой месяца) → ягодная карточка «Осталось сегодня» (без узора) → три карточки с едой в один ряд (курочка = белки, авокадо = жиры, макарошки = углеводы) → «Что в тарелке?» с сердечком-микрофоном → «Съедено».
- Все тексты нейтральные по роду — подходят и девушкам, и парням.

## Как работать
- Править `index.html`, коммитить в `main` — GitHub Pages обновляется сам за 1–2 минуты.
- Сначала показать изменения в локальном предпросмотре и выкладывать только после подтверждения.
- Общаться по-русски, простым языком, без лишних технических терминов.
